StageChord is a mobile-friendly viewer for songs written in ChordPro format. All your songs and settings are stored on your device — nothing is sent to a server, and the app works offline once installed.

Getting Started

ChordPro is a simple text format that puts chord names in square brackets above the lyrics, like [G]Amazing [C]grace. You can find ChordPro files online, or create your own in any text editor.

To get started, add some songs using the ☰ Manage menu, or import a song library from the Song Libraries section above.

Adding Songs

Open the ☰ Manage menu and tap Add Songs to Library. You can select one or more .chopro, .chordpro, or plain text files from your device.

Songs are stored in your library on the device. After adding, use Browse Library to select which songs to include in your current set.

You can also import song libraries directly from the Song Libraries section on this page.

Song Navigation & Order

When you have multiple songs in your set, use the Prev Song / Next Song buttons or the dropdown to switch between them.

Tap the Song Order button to expand the reorder panel. Use the ↑ and ↓ arrows to rearrange songs, then tap Done.

Section jumps: Songs with sections (e.g. Verse, Chorus, Bridge) show quick-jump buttons in the navigation bar. Tap a section name to scroll directly to it.

Transposing

Each song displays its key (detected from the {key: ...} directive, or inferred from the first chord). Use the − and + buttons to transpose up or down in semitones.

The key display shows the transposed key, e.g. Key: G. Transpose settings are saved per song and persist across sessions.

StageChord uses correct enharmonic spelling for each key — sharp keys show sharps, flat keys show flats.

Editing Chords & Lyrics

Tap the ✎ Edit button to enter edit mode.

  • Change a chord: Tap any chord to open a popup with all chords used in the song. Select a different chord, type a custom chord, or delete it.
  • Add a chord: Tap any lyric word or space to insert a new chord at that position.
  • Edit key & tempo: In edit mode, the key and tempo fields become editable text inputs.
  • Reset: If you've made changes, a Reset button appears to revert to the original version.

Tap ✓ Done to exit edit mode. All edits are saved automatically.

Auto-Scroll

Tap the green Scroll button to start automatic scrolling from the top to the bottom of the song. The scroll takes about 3 minutes.

If you manually scroll, touch the screen, or press a key, auto-scroll pauses for 2 seconds then resumes. Tap the red Stop button to end scrolling.

Tempo Flash

If a song has a tempo set (e.g. {tempo: 120}), a Tempo button appears next to the key. Tap it to flash the navigation bar in time with the beat — useful for counting in.

Tap again to stop the flash. It also stops automatically when you change songs.

Musical Stave (Notation)

Add a line of musical notation above any song by tapping the +Stave button (or ✎ Stave to edit an existing one).

The stave editor lets you:

  • Choose a time signature (4/4, or 6/8)
  • Select note duration — from semibreve to semiquaver, with dotted and tied options
  • Set accidentals (sharp, flat, natural)
  • Change octave (8va up, 8vb down)
  • Add barlines and rests
  • Enter notes using the pitch buttons (scale-aware for the song's key)

The stave is rendered as standard musical notation and transposes along with the song's chords when you change key.

Comments & Annotations

Tap +Comment to add a personal note to a song — for example, performance reminders, capo positions, or arrangement notes.

Comments are displayed in a highlighted box above the song. Tap ✎ Comment to edit or remove an existing comment.

Sets (Setlists)

A set is a collection of songs in a specific order — perfect for gigs or practice sessions.

  • New Set: Clears the current set to start fresh.
  • Save Set: Saves the current set with a name. You can overwrite an existing set or create a new one.
  • Load Set: Opens a picker showing all saved sets with their song counts. You can also delete sets from this picker.
  • Import Set: Load a .stagechord.json set file. Songs are added to your library and the set is created automatically.

Your current set (song order and position) is automatically remembered between sessions, even without saving.

Sharing Sets

Share your setlist with bandmates in two ways:

  • Share as Link: Generates a URL containing the entire set (compressed). Send the link via messaging — recipients open it in their browser and the set imports automatically. Note: very large sets may exceed URL length limits.
  • Share as File: Sends a .stagechord.json file via your device's share menu (or downloads it). The recipient imports it through the menu.

Song Library

Your library contains all songs you've added or imported. From the menu:

  • Add Songs to Library: Import .chopro or text files from your device.
  • Browse Library: View all songs, select which to add to your current set, or delete songs you no longer need.

Songs in the library persist until you delete them. Transpose settings, staves, and edits are saved per song.

Import & Export

Library

  • Export Library: Downloads your entire library as a .json file — includes all songs, transpose settings, staves, and edits. Great for backups.
  • Import Library: Loads a previously exported library file. You'll be asked whether to add alongside existing songs, replace your library entirely, or export a backup first. Duplicate songs (identical content) are automatically skipped.

Installing as an App

StageChord can be installed on your device for quick access and offline use:

  • Android: Tap the browser menu (⋮) → "Add to Home screen", or use the Add as App option in the ☰ Manage menu.
  • iPhone / iPad: Tap the Share button (⬆) → "Add to Home Screen".

Once installed, the app works fully offline — your songs and settings are stored on your device.
